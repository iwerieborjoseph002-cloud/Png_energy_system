# PNG Energy System – Dependency Graph

## 1. Introduction

The dependency graph represents the structured flow of chemical, mechanical, and control processes within the PNG Energy System. It defines how each module depends on upstream physical processes and how feedback is used for system-level optimization.

This system is not linear. It is a multi-layer energy conversion architecture combining:
- chemical production
- fuel processing
- combustion dynamics
- control feedback
- system expansion logic

## 2. System Overview

The PNG Energy System operates as a coupled multi-domain system:

- Chemical Layer → fuel creation from raw reactants  
- Fuel Processing Layer → conditioning and delivery of fuel  
- Combustion Layer → energy release and stability analysis  
- Control Layer → sensing and diagnostics  
- Optimization Layer → feedback and system tuning  
- Expansion Layer → future integration and scaling

## 5. Feedback Loop Definition

The system operates as a closed-loop control system.

Sensor data from combustion and atomization behavior is fed into the optimization module to adjust:

- fuel injection parameters  
- atomization characteristics  
- catalyst efficiency assumptions  
- combustion stability thresholds
