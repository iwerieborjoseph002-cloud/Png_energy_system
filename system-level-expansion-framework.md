## 6.0 Core Reference Reaction

The PNG system is fundamentally anchored on the chemical conversion process:

C + H₂O(g) → CO + H₂

This reaction defines the base thermochemical conversion pathway upon which all system-level expansions are built.

## 6.1 Module Definition

The Expansion Layer is a system-level architecture module responsible for:
- scaling the PNG Energy System beyond a single engine unit  
- defining multi-node deployment structures  
- enabling environmental adaptability  
- supporting future system integration without modifying core chemistry  

It operates as a structural evolution layer rather than a physical modification layer.

# 6.8 Quantitative Scaling Model (NEW)

To introduce measurable structure, system expansion can be expressed conceptually as:

- Expansion Factor (EF) = Number of Active Nodes / Base Node
- System Efficiency (SE) = Output Energy / Input Energy
- Scaling Efficiency (SCE) = SE × EF Adjustment Coefficient

Where:
- EF > 1 indicates distributed expansion
- SE determines energy performance stability under scaling

This provides a foundation for future computational modeling.

# 6.9 Failure & Limitation Behavior (NEW)

The Expansion Layer includes structural limits:

### Failure Conditions:
- node instability under overload
- thermal imbalance between distributed units
- sensor desynchronization across nodes
- efficiency drop beyond scaling threshold

- recalibration of operational parameters
- isolation of unstable nodes
- rebalancing of system load distribution
