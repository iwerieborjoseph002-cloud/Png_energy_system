# Code of Conduct – PNG Energy System Project

## 1. Purpose

The PNG Energy System Project is a structured engineering and research initiative focused on fuel atomization, catalytic processes, combustion dynamics, and system-level energy modeling.

This Code of Conduct defines the expected standards of behavior for all contributors to ensure:
- technical integrity
- consistent documentation quality
- respectful collaboration
- structured scientific development

---

## 2. Expected Behavior

All participants are expected to:

- Maintain professional and respectful communication
- Focus on technical and engineering accuracy
- Support contributions with logical reasoning or references where applicable
- Respect the modular structure of the repository
- Engage constructively in discussions and reviews
- Accept feedback in a collaborative and scientific manner

---

## 3. Technical Integrity Standards

Because this project is engineering and research-based:

- All scientific or engineering claims must be logically supported
- Conceptual ideas must be clearly distinguished from validated analysis
- Contributions must align with the existing 7-module system structure
- No module should be modified without considering system-wide impact
- Duplicate or conflicting logic must be avoided

---

## 4. Unacceptable Behavior

The following behaviors are not allowed:

- Unsupported or misleading technical claims
- Breaking module structure or dependency logic
- Introducing unrelated or inconsistent system designs
- Plagiarism or unattributed content
- Disruptive or disrespectful communication
- Deliberate distortion of engineering analysis or results

---

## 5. Collaboration Principles

This project encourages:

- Iterative improvement of engineering models
- Structured technical discussion
- Transparent module refinement
- System-level thinking across all contributions
- Continuous improvement of documentation quality

All contributions should improve clarity, consistency, and system coherence.

---

## 6. Issue Resolution and Enforcement

If a violation occurs:

1. The issue will be reviewed based on technical and structural impact  
2. Contributors may be asked to revise or clarify their submission  
3. Repeated violations may result in restricted contribution access  

The goal is correction and alignment, not punishment.

---

## 7. Scope of This Code

This Code of Conduct applies to:

- All repository modules
- Pull requests
- Issue discussions
- Documentation edits
- System architecture proposals

---

## 8. Project Philosophy

The PNG Energy System Project is built on the principle that:

Engineering systems must remain logically structured, scientifically consistent, and continuously improvable through disciplined collaboration.
